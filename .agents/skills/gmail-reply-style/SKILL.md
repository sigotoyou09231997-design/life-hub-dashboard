# Gmail返信スタイル（船田悦司・転職活動用）

過去の送信履歴（2026年5月〜8月、29スレッド）から抽出された、実際に使われている傾向を元に件ごとに構成が決まっているので、まず件を判定し、該当するパターンに当てはめて書く。

## 展開ルール

- 書き出しは基本2行固定：
  ```
  お世話になっております。
  船田です。
  ```
  フォーマル度が高い相手（人材紹介会社・企業直接連絡・お礼・謝罪）では、冒頭に社名 `会社名　担当者様` を足し、名乗りも「船田（悦司）です」とワンテンポ入れる。
- 末尾は件で使い分ける：
  - 日常的なやり取り（書類送付・確認・相槌）→「よろしくお願いします。」
  - フォーマルな依頼・謝罪・お礼 →「よろしくお願いいたします。」／「何卒よろしくお願いいたします。」
- 絵文字・記号は使わない。淡々としたビジネストーンを保つ
- 前置きは短く、余計な世間話は入れない。件に入るまで最短で2行
- 署名ブロック（氏名・連絡先を改めて書く）は付けない。末尾は「よろしくお願いします」系の一文で終わる

## パターン別テンプレート

### A. 書類提出

```
お世話になっております。
船田です。
こちら履歴書と職務経歴書になります。
ご確認ください。
よろしくお願いします。
```
派生表現：「履歴書と職務経歴書を（お送りします／添付いたします）よろしくお願いします」の直後に、「以下、お目通しいただけますと幸いです」などを付け足すこともある。

### B. 面接・面談日程の調整

```
お世話になっております。
船田です。
（ご連絡いただきありがとうございます）
下記の日程で、ご調整いただけますと幸いです（対応可能です）。

第1希望：○月○日（○）19:30〜
第2希望：○月○日（○）19:30〜
第3希望：○月○日（○）19:30〜

ご確認のほど、よろしくお願いいたします。
```
- 候補日は3〜5件出す。「第○希望：」など箇条書きで統一
- 現職の都合を伝える定型文（そのまま使う）：
  「現在在職中のため、平日は19時30分以降での面接を希望しております。」
  「現職の都合により平日の調整が難しく感じております。上記の日程でご調整いただけますと幸いです。」

### C. 相手の提案への承諾・確認・相槌

```
お世話になっております。
船田です。
（ご連絡いただきありがとうございます／かしこまりました）
当日はよろしくお願いいたします。
```
2〜3文で完結する、事前連絡（連絡先変更の指示など）への返信は軽く簡潔に済ませる。

### D. 謝罪・依頼・キャンセル（宛先の丁寧度を積み増すパターン）

4段構成で書くので、他のパターンより長くなっている。

```
（会社名　担当者様）
船田（悦司）です。

[お礼]このたびは○○いただき、誠にありがとうございます。
[謝罪]大変恐縮ではございますが、ご迷惑をおかけしますこと、心よりお詫び申し上げます。
[本題]慎重に検討いたしました結果、今回は○○とさせていただきたく、ご連絡いたしました。
（[代替案があれば提示]）

何卒よろしくお願いいたします。
```
使用シーン：キャンセル・謝罪・依頼のような、大変申し訳ない気持ちを丁寧に伝えたい場面で使う。「大変恐縮ですが」「心よりお詫び申し上げます」「重ねてお詫び申し上げます」などのワンクッション言葉を使い、大変恐縮ではございますが／申し訳ございませんが、を随所に挟む。

## 判断フロー

1. 件は何か？ → 書類提出（A）／日程調整（B）／承諾・相槌（C）／謝罪・依頼・キャンセル（D）
2. 相手は人材紹介会社・企業直接連絡・フォーマル度高い？ → 敬称を追加、末尾は「よろしくお願いいたします」系に統一
3. 日程の話が絡む？ → 在職中の場合、平日19:30以降希望の一文を必ず検討
4. つれづれ対応（謝罪・依頼）？ → パターンDで、お礼→謝罪→本題→代替案の順を崩さない

## 避けたいこと

- 長い前置きや世間話
- 絵文字や過度な記号
- テンプレートA〜Cの件にパターンDの謝罪表現を混ぜること（件に対して丁寧すぎると不自然）
