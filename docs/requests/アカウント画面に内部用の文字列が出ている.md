# アカウント画面に、開発用と思われる文字列がそのまま表示されている

## 何を変えたいか
アカウント画面の「この端末のアカウント」カードで、自分のアカウント行の下に

「登録1件 [a74acf/life-hub/slot=既定] / 開いているDB=life-hub / 複製先=0件」

という、内部の識別子やデータベース名らしき文字列がそのまま表示されている。
デバッグ用に残っているものだと思うので、一般利用者には見せない形にしてほしい
(完全に消す、または開発者だけが見られる場所に移すなど、判断はお任せします)。

## どの画面／どのデータか
アカウント画面(/account)の「この端末のアカウント」カード、自分のアカウント行の
すぐ下にある小さいグレーの文字列。

## 既存データをどう扱うか
表示(見た目)だけの変更。アカウントやデータそのものには手を入れない。
