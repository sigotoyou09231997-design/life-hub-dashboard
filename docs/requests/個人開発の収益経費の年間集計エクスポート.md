# 個人開発の案件ごとの収支を年間でまとめてエクスポートしたい

## 何を変えたいか
個人でWeb開発の仕事もしているので、案件・プロジェクトごとにタグを付けた支出・収入を、
確定申告のために年間でまとめてエクスポートできるようにしたい。
今のTransactionCsvExportはカテゴリ単位の出力で、案件単位の集計はできない。

## どの画面／どのデータか
お金管理 → 支出・収入の一覧、エクスポート機能(TransactionCsvExport.tsx)。
Transactionに案件タグのような項目を追加するイメージ。

## 既存データをどう扱うか
過去の支出・収入は未タグのままでよい。タグを付けたものだけ案件別集計に出る形。
