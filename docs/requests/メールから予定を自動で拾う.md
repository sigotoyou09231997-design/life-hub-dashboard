# Gmail連携で、メールから予定を自動で拾えるようにしたい

## 何を変えたいか
設定画面のGmail連携は今「受信メールにAIが返信案を作成する」機能だけになっている。
これに加えて、面接の日程確定メールや予約確認メールのように日時が書かれたメールを
検知したら、その内容から「予定を追加しますか?」と提案してくれる機能が欲しい。
提案止まりでよく、本人が確認して追加を押すまでは予定表に反映しなくてよい。

注記: これはメールの内容をAIに読ませて日時を抜き出す処理が増える可能性が高く、
API呼び出し回数が増える変更にあたるかもしれません。その場合は依頼のルールどおり
実装せず、`.cowork/waiting.txt` に理由を書いて止めてもらって構いません。

## どの画面／どのデータか
Gmail連携画面(/gmail)、および設定画面のGmail連携部分。
予定・タスク管理側には「提案」として一時的に出す形を想定(お任せします)。

## 既存データをどう扱うか
既存のメール・予定データには手を加えない。あくまで新しい提案の仕組みを追加するだけ。
