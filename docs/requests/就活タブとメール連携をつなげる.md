# 就活タブと、メールから予定を拾う機能をつなげたい

## 何を変えたいか
すでにある「就活」タブと、Gmail連携の「メールから予定を拾う」提案機能を
組み合わせたい。選考結果のメール(通過・見送り・日程調整など)を検知したら、
就活タブの該当する応募先の進捗(書類選考・一次面接・二次面接・内定など)を
自動で更新する提案をしてほしい。予定の提案と同じく、提案止まりでよく、
本人が確認して反映を押すまでは進捗を変えなくてよい。

注記: これはメールの内容をAIに読ませて判定する処理が増える可能性が高く、
API呼び出し回数が増える変更にあたるかもしれません。その場合は依頼のルール
どおり実装せず、`.cowork/waiting.txt` に理由を書いて止めてもらって構いません。

## どの画面／どのデータか
Gmail連携の提案の仕組み、および予定・タスク管理の「就活」タブ。

## 既存データをどう扱うか
既存のメール・就活の記録には手を加えない。あくまで新しい提案の仕組みを追加するだけ。
