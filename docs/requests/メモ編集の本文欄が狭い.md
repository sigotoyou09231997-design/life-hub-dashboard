# メモを編集するときの「本文」欄が狭くて見づらい

## 何を変えたいか
メモ・リストで「メモを編集」を開いたとき、本文の入力欄が縦に狭く、
住所のような数行のテキストを入れると、下の方が枠内に収まらず
スクロールしないと見えない状態になっている。
本文欄をもっと広く(縦に長く)して、入力した内容がひと目で見えるようにしてほしい。

添付のスクリーンショットのとおり、タイトル直下の本文欄が4行分くらいしかなく、
実際に入れた住所・会社名などが下に隠れてしまっている。
添付: screenshots/メモ編集_本文欄が狭い.png(実際のChromeで撮影)

## どの画面／どのデータか
メモ・リスト画面の「メモを編集」ダイアログ、本文(任意)の入力欄。
新規作成時のダイアログも同じ入力欄を使っていれば、そちらも合わせてほしい。

## 既存データをどう扱うか
見た目(入力欄のサイズ)だけの変更。既存のメモの内容は変えない。
