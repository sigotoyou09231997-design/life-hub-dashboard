# ホームを参考デザインにもう少し寄せる

## 何を変えたいか

本人が今のホームを `docs/requests/screenshots/デザイン参考_LIFEHUB案.png` と見比べたところ、
「ちょっと違う」とのこと。できる限り画像に寄せたい。

**ただし、今日すでに本人の指示でホームから削除した次の4つは、今回の対象に含めない（復活させない）。**

- あいさつ（「おはよう、〇〇さん」＋一言） — 1240214
- 今日のハイライト（達成率リング＋色つきドットの統計） — 50546c3
- 丸いクイック操作アイコンの行（予定・タスク・お金管理・メモ・Gmail・旅行） — 562d9b0
- 下段の写真つき機能カード6枚 — fe60abc

これらはいずれも参考画像には写っているが、本人が意図して消したもの。参考画像に寄せるという
理由だけで戻さないでほしい。

**今回は、今も残っている部分（ヒーロー・次の旅カード・4分割のリストカード・サイドバー・
配色や角丸などの土台）を対象に、もう少し参考画像に近づける。** 気になっている点は次の3つ。

### 1. ヒーローの書体

参考画像の「10:30 AM」は丸みのある太い書体。その下の「Stay focused, enjoy life.」は
斜体のセリフ体（明朝寄り）に見える。いまはどちらも本文と同じ丸ゴシック（system-ui系、
`--font-display`）で、ひとことの斜体もそのゴシックに `font-style: italic` を掛けているだけ
（`src/styles/home-warm.css` の `.warm-hero__clock` / `.warm-hero__quote`）。

時刻とひとことで書体を分けたい。時刻はもう少し丸みの強い書体、ひとこと
（`warm-hero__quote`）は斜体のセリフ系にしてほしい。

注意: 日本語のフォントはイタリック体を持たないものが多く、`font-style: italic` だけだと
単に斜めに潰れて見えることがある（ブラウザの疑似斜体）。ひとこと（「静かに、今日を始める。」
など、`src/pages/TopPage.tsx` の `HERO_PHOTO`）は日本語なので、実際に当ててみて不自然なら
無理に斜体にしなくてよい。

### 2. ヒーローの写真

いまは `public/backgrounds/*-v5.jpg`（暖色フィルタをかけた室内・建築の素材）を時間帯で
出し分けている（`TopPage.tsx` の `HERO_PHOTO`）。参考画像は、窓辺・生成りのソファ・
青みのクッション・小さな花瓶のような、もう少し明るく生活感のある写真。

これは新規デザインの依頼（デザインを暖色・写真ベースの新デザインに全面刷新.md）の時点から
「写真素材が仮のまま」として引き継がれていた点（`.cowork/apps/todoアプリ/waiting.txt` の
解決済み欄を参照）。差し替えるにはネットワークの使えるセッションで探して `public/` に
同梱する必要があるため、今回のヘッドレス実行では手が出ない可能性が高い。

無理に差し替えなくてよい。差し替えが必要と判断したら、`.cowork/apps/todoアプリ/waiting.txt`
に「ネットワークが要るため保留」と書いて止めてもらえれば、次にCoworkの方で候補写真を探して
別の依頼として渡す。

### 3. サイドバー下部の「アカウント」

参考画像はサイドバー下部が、丸い写真アバター＋名前＋プランのような「プロフィールカード」の
見た目（`src/components/layout/DesktopSidebar.tsx` の `.sidebar-account`）。いまは
`UserRound` アイコン＋「アカウント」の文字だけ。

中身（プラン表示など）はこのアプリに無い情報なので出さなくていい。見た目だけ、もう少し
カードらしく（丸みのある背景・余白・アイコンを大きめの円に収めるなど）寄せられるなら
寄せてほしい。優先度は低い（1・2よりあとでよい）。

## どの画面／どのデータか

ホーム（`src/pages/TopPage.tsx`, `src/styles/home-warm.css`）と、サイドバーの
アカウント欄（`src/components/layout/DesktopSidebar.tsx`）の見た目だけ。
デスクトップ幅・モバイル幅の両方が対象。データ・挙動・ロジックは変えない。

## 既存データをどう扱うか

触らない。変えるのはフォント指定・写真アセット・サイドバーのアカウント欄のCSSだけ。

## 進め方について

3点とも独立しているので、まとめてやらなくてよい。できたところまでで構わない。
判断に迷う細部（フォントの具体的な銘柄・数値など）は、これまでどおり妥当な案で進めてよい。
