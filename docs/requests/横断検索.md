# 予定・メモ・Gmail・旅行をまとめて検索したい

## 何を変えたいか
いまは予定・タスク、メモ、Gmail、旅行のルート画面にそれぞれ個別の検索ボックスがあるが、
「あの店の名前、どこに書いたか忘れた」というときに、全部をまとめて検索する方法が無い。
1か所で検索すると、どの機能のどのデータに一致したか分かる形で結果が出るようにしたい。

## どの画面／どのデータか
- 新しい横断検索の入り口（TOP画面やヘッダーなど、自然な場所でよい）
- 対象データ：予定(CalendarEvent)、タスク(Task)、メモ・リスト(Note)、旅行関連(Trip, TripScheduleItem等)
- Gmail(SyncedEmail)は対象に含めるかどうか実装しやすい範囲で判断してよい

## 既存データをどう扱うか
既存の各画面の個別検索はそのまま残してよい。新しい横断検索は追加機能として作る。
