# 全体的にベージュが強すぎるので薄くする

## 何を変えたいか

暖色デザインは本番に出したが、見てみると全体的にベージュ（生成り）の色味が強すぎる。
添付の参考画像（`screenshots/デザイン参考_LIFEHUB案.png`、最初に渡したものと同じ）と見比べると、
参考の方はほぼ白に近い、ごくうっすらとした色味のクリームで、カードの白との差がはっきりしている。
今の本番は、地の色そのものがはっきり「ベージュ」と分かる濃さで、カードの白との差が少なくて
全体がぼやっと同じ色に見える。

具体的に疑わしい点:
- ページ全体の背景（`--warm-ground-*` あたり）の色が、参考より一段階か二段階濃い・彩度が高いと思う。
  もっと白に近づけてほしい。
- 予定・タスクやお金管理、設定などのページ上部にある、写真を敷いた色つきの帯（見出しの背景）。
  参考画像にはこの帯が無く、見出しはただの白地に黒文字。この帯がベージュ感を強めている
  一番の原因だと思うので、無くすか、今よりだいぶ薄く・目立たなくしてほしい。
- カード（白いカード）と背景の差がもっとはっきり見えるように、背景を薄く・カードとの明度差を
  今より大きくしてほしい。

## どの画面／どのデータか

全画面共通の色トークン（`src/styles/theme-warm.css`など）。特定の1画面だけの問題ではなく、
色の土台の話なので直せば全画面に効くはず。データ・挙動は変えない。

## 既存データをどう扱うか

触らない。見た目（色味）のみの調整。

## 進め方について

前回までと同じで、`design/warm-photo-refresh`のような作業用ブランチで進めて、
本人が見た目を確認してから本番へ入れる形にしてほしい。今回は色の濃さの調整だけなので、
そこまで大きな変更にはならないと思う。
