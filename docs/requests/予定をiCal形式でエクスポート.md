# 予定をiCal形式(.ics)でエクスポートできるようにしたい

## 何を変えたいか
予定・タスク管理の予定を、iPhoneの標準カレンダーやGoogleカレンダーにも
取り込める形式(.icsファイル)で書き出せるようにしたい。
家族と予定を共有したり、他のカレンダーアプリと二重管理せずに済むようにしたい。

全部の予定をまとめて1つのファイルに書き出す形でよい(お任せします)。

## どの画面／どのデータか
予定・タスク管理画面、またはお金管理のCSV書き出しと同じような場所(設定画面など)。

## 既存データをどう扱うか
既存の予定データは読み取るだけで、変更・削除はしない。書き出し(エクスポート)
だけの機能。
