## 何を変えたいか

`supabase/sql/021_trip_expense_currencies.sql` と `supabase/sql/022_transaction_project_tags.sql` を
Supabase の SQL Editor で順番に実行し、両方とも成功しました（エラーなし）。

`trip_expense_currencies` と `transaction_project_tags` の2テーブルが本番に用意できたので、
案内どおり2段階目として `src/lib/syncRuntime.ts` に以下を足してください。


## どの画面／どのデータか

`src/lib/syncRuntime.ts` の同期登録のみです。画面の見た目は変わりません。

## 既存データをどう扱うか

追加登録のみで、既存の同期テーブル・データには影響ありません。各端末に残っている
通貨内訳・案件タグのローカルデータは、登録後の初回同期でSupabaseへ上がっていく想定です。
