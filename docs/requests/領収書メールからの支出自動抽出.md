# 注文確認・領収書メールからも支出を自動で拾いたい

## 何を変えたいか
今のレシートスキャン(receiptScan.ts)は画像を撮って読み取る形だけ。
Amazonなどの注文確認メールや領収書メールからも、同じように支出の候補
（金額・店名・日付）を拾って登録を提案してほしい。

## どの画面／どのデータか
Gmail連携の同期処理(gmailSync.ts)まわり。提案の出し方は、予定の提案
(mailPlanSuggestion.ts)や就活の提案(jobMailSuggestion.ts)と同じ形でよい。

## 既存データをどう扱うか
既存メールは対象外でよい。これから同期する新着メールだけ判定する。
