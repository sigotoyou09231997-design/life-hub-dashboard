# 予定・タスク管理「今日」タブ、タスクカードの空状態の文言がおかしい

## 何を変えたいか
予定・タスク管理画面の「今日」タブで、タスクが0件のときに右側のタスクカードに
表示される文言が

「今日のControlは整っています」

となっていて、日本語の文の中に英単語(Control)がそのまま混ざっていて不自然。
自然な日本語の文言に直してほしい(具体的な言い回しはお任せします)。

## どの画面／どのデータか
予定・タスク管理画面(/schedule)の「今日」タブ。タスク0件のときの、
右側「今日のタスク」カードの空状態メッセージ。

## 既存データをどう扱うか
文言だけの変更。既存データの扱いは変えない。
