# 背景は真っ白でいい（前回の「ベージュを薄く」の続き・追加指示）

## 何を変えたいか

直前の依頼「全体的にベージュが強すぎるので薄くする」の続き。単に薄くするだけでなく、
**ページの背景は添付の参考画像（`screenshots/デザイン参考_LIFEHUB案.png`）通り、真っ白でいい**、
とのこと。うっすらクリームを残す必要はない。`--warm-ground-*`系の背景トークンを白（#ffffff、
または白に限りなく近い色）にしてほしい。

カード自体も白なので、カードの縁取り・影で区切りが分かれば十分。
写真（ホームのヒーロー写真や機能カードの写真）や、ロゴなど元々色のある要素はそのままでよい。
あくまで「地の色」の話。

## どの画面／どのデータか

`src/styles/theme-warm.css`などの色トークン。全画面共通。データ・挙動は変えない。

## 既存データをどう扱うか

触らない。見た目（色味）のみ。

## 進め方について

直前の依頼で作った`design/warm-lighter-ground`ブランチ（あれば）の続きでよい。
確認してから本番へ、という進め方も同じで構わない。
