# タブ切り替えボタンの見た目を統一してほしい

## 何を変えたいか

添付の2枚のスクショ（お金管理のサマリー/給与/固定費/履歴/カード/PayPayの6タブと、
メモ・リストの メモ・リスト/日記 の2タブ）を見比べると、同じ「タブ切り替え」の見た目
（ボタンの大きさ・余白・角丸・選択中の見せ方など）が画面によって揃っていません。

依頼者の意図は「大きくしてほしい」ではなく「画面ごとにバラバラなのを統一してほしい」です。
どちらの見た目に寄せるかはお任せします。アプリ内の全部のタブ切り替え（旅行詳細・予定タスク
なども含む）で、同じ見た目になるようにしてください。

## どの画面／どのデータか

タブ切り替えの共通部品（`src/components/ui/Tabs.tsx` 想定）と、それを使っている全ページ
（お金管理・メモ/リスト・日記・旅行詳細・予定タスクなど）。

## 既存データをどう扱うか

見た目だけの変更で、データには影響ありません。
