# 予定・タスクの繰り返しを曜日指定できるようにしたい

## 何を変えたいか
予定(CalendarEvent)・タスク(Task)の繰り返し(RepeatRule)は今、daily/weekly/monthlyの
3種類しかない。「毎週月・水・金だけ」のように曜日を複数指定して繰り返せるようにしたい。

## どの画面／どのデータか
予定・タスクの追加編集フォームの繰り返し欄。判定ロジックはsrc/lib/eventSpan.tsの
occursOn/spanDayIndexまわり。

## 既存データをどう扱うか
すでに入っているweekly設定は、今まで通り「開始日と同じ曜日だけ」として動けばよい。
曜日を複数選ぶ新しい設定は、これから作る予定・タスクから使える形でよい。
