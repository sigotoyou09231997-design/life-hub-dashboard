# カテゴリ予算を超える前に知らせてほしい

## 何を変えたいか
カテゴリ別予算(CategoryBudget)の通知は今、超えたあとに届く(checkBudgetAndNotify.ts)。
そうではなく、「今のペースで使い続けると給料日までに超えそう」というタイミングで
事前に知らせてほしい。

## どの画面／どのデータか
お金管理のカテゴリ別予算まわり。通知はcheckBudgetAndNotify.tsと同じ通知の仕組みに
予測ロジックを足すイメージ。集計期間はcategoryBudget.tsに合わせて給料日〜次の給料日。

## 既存データをどう扱うか
特に移行は不要。既存のカテゴリ予算設定にそのまま予測判定を足す形でよい。
