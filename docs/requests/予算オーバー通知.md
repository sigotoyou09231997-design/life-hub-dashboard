# 使いすぎ・予算オーバーの通知がほしい

## 何を変えたいか
お金管理には「現在使える残額」「1日あたり使える金額」の計算が既にあるが、
これがマイナスになった、あるいは一定額を下回ったときに気づく手段が今は無い。
固定費や旅行の予定と同じように、push通知で知らせてほしい。

## どの画面／どのデータか
- お金管理の残額計算（1日あたり使える金額を出している箇所）
- 既存のpush通知の仕組み（固定費の通知などと同じ基盤）を使う
- 通知の閾値は実装しやすい形で構わない（例えば「残額がマイナスになったら」だけでもよい）

## 既存データをどう扱うか
既存の支出・固定費・給与データの扱いは変えない。通知の追加のみ。
