# 貯金目標を複数(名前つき)で持てるようにしたい

## 何を変えたいか
設定画面の「貯金目標」が今は「毎月の目標額」1つだけになっている。
これを「旅行用」「生活防衛費用」のように名前をつけて複数持てるようにしたい。
それぞれの進捗(お金管理のサマリーに出ているような「今期の残額が目標に届きそうか」)
も目標ごとに見られるとうれしい。

## どの画面／どのデータか
設定画面の「貯金目標」、およびお金管理のサマリー画面(進捗表示部分)。

## 既存データをどう扱うか
今すでに設定されている1つの目標額は、消さずに新しい仕組みに引き継いでほしい
(例えば「目標1件目」として残す、など、やり方はお任せします)。
