# 貯金目標の進捗を見えるようにしたい

## 何を変えたいか
Settings型にはすでに savingsGoalMonthly（毎月の貯金目標額）というフィールドがあるが、
どの画面からも参照されておらず、実質使われていない。今月あとどれくらい貯金目標に対して
余裕があるか／届きそうかを、お金管理の画面で確認できるようにしたい。

## どの画面／どのデータか
- お金管理TOP（既存の「現在使える残額」「1日あたり使える金額」を出している箇所）
- 設定画面（savingsGoalMonthlyを編集できる入力欄が無ければ追加する）
- データはSettings.savingsGoalMonthlyを使う

## 既存データをどう扱うか
savingsGoalMonthlyの値が0または未設定の場合は、目標未設定として何も表示しない（強制しない）。
既存の残額計算ロジックは変更しない。
