# 旅行の支出が予算を超えそうなときに通知してほしい

## 何を変えたいか
旅行の支出(TripExpense)が旅行の予算(Trip.budget)に対してどれだけ残っているかは
一覧(TripExpenseList.tsx)に表示されるが、見に行かないと分からない。
近づいた/超えたときに、家計のカテゴリ予算超過通知(checkBudgetAndNotify.ts)と
同じような仕組みで能動的に知らせてほしい。

## どの画面／どのデータか
旅行計画 → 旅行の支出。通知はcheckBudgetAndNotify.tsに相当する仕組みに追加するイメージ。

## 既存データをどう扱うか
影響なし。予算(budget)が設定されている旅行だけが対象でよい。
