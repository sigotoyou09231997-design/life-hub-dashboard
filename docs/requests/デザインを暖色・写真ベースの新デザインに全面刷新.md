# デザインを暖色・写真ベースの新デザインに全面刷新

## 何を変えたいか

いま進めている「リキッドグラス」路線（ダーク・半透明ガラス調。着手済みは HOME 画面のみ）は
この依頼でやめて、添付画像 `screenshots/デザイン参考_LIFEHUB案.png` の方向に全面的に作り直したい。

**機能・挙動・データは一切変えない。見た目（色・フォント・角丸・カードの組み方・写真素材・アイコンの意匠）だけを差し替える。**
HOME 画面も含めて、今のリキッドグラス実装のコードは使わなくていい（置き換えてよい）。

### 参考画像の特徴（添付: デスクトップ幅とスマホ幅の両方が写っている1枚）

- 背景はダークではなく、生成りっぽい暖色のクリーム/オフホワイト。ガラスのぼかし表現は使わない。
- カードの角丸は大きめ（16〜24px相当）で、影は柔らかく薄い。ガラス調のにじみ・境界線の光沢は無し。
- 生活感のある実写写真をあちこちに使っている：ホームのヒーローは部屋・窓からの眺めの写真、
  下段には貯金箱・コーヒー・スーツケース・ノートと鉛筆・観葉植物などの写真カードが並ぶ。
- ホーム上部は「10:30 AM」のような大きな時刻表示（丸みのある太めの書体）＋日付＋
  「Stay focused, enjoy life.」のような斜体の一言。
- 「おはよう、Harukiさん 🌿」のような親しみのある挨拶ヘッダー（絵文字つき）。
- 円形の達成率リング（72%など）＋色つきドットのついた統計リスト（タスク進捗、支出、予定完了など）。
- クイック操作は、色分けされた円形アイコン（予定=青、タスク=緑、お金管理=紫、メモ=オレンジ、Gmail=赤 など）
  を横並びにした行。カテゴリごとに色を固定して使う。
- 「次の予定」「今日のタスク」「今月のお金」「Gmail」のような4分割のリストカードが並ぶダッシュボード構成。
- 一番下は写真つきの機能カードのグリッド（写真＋タイトル＋一言説明）。
- ロゴまわりに葉っぱ/植物のモチーフ（アイコンや余白の装飾）。
- サイドバーは白〜クリームの背景で、選択中の項目だけ薄い色のかたまりでハイライト。下部にユーザーの
  プロフィールカード（アバター写真・名前・プラン表示）。
- スマホ幅では下部タブバー＋中央に浮いた丸い「＋」ボタンという構成（現状のモバイルナビと考え方は近いはず）。

## どの画面／どのデータか

見た目だけの話なので、アプリの全画面が対象。今の左サイドバー／モバイル下部ナビの並び通りに、
それぞれこの新しいトーンに合わせてほしい。

- ホーム
- 予定・タスク（今日／カレンダー／一覧／就活の各タブ）
- お金管理
- メモ・リスト（メモ／日記／チェックリスト／買い物リストの各タブ）
- Gmail
- 旅行計画（一覧・詳細とも。詳細側のタブ＝日程／費用／持ち物／ルート／日記も含む）
- ふりかえり（週ごと／月ごと）
- 設定
- アカウント
- デスクトップ幅・モバイル幅の両方。サイドバー／モバイル下部ナビ自体の見た目も対象。

参考画像に出てくる「プロジェクト定例会議」のような画面内容はダミーなので気にしなくていい。
今アプリに実在する項目・データ・文言はそのまま使い、見た目のトーン（色・角丸・カード構成・写真の使い方）
だけをこの参考に寄せてほしい。

## 既存データをどう扱うか

触らない。表示ロジック・計算・保存先・Supabase/IndexedDBの構造はすべて現状維持。
変えるのは UIコンポーネント／CSS・Tailwindの設定／画像アセットだけ。

今アプリの背景に使っている空や山の写真（ホームのヒーローなど）は、今回のトーンには合わないので
使わなくていい。旅行機能で使っている部屋・街並みの写真は雰囲気が近いので、流用してもそのままで構わない。

## 写真素材について

新しく素材を探して差し込んでよい（無料で商用利用できるライセンスのものに限る。Unsplash等）。
参考画像にある被写体（部屋の窓辺、観葉植物、貯金箱、コーヒー、スーツケース、ノートと鉛筆など）に
近いテイストで、暖色・ナチュラルな色味に統一してほしい。被写体そのものを完全に一致させる必要はない。

写真は一度ダウンロードして `public/` 配下などに最適化して同梱する形にしてほしい（外部URLへの
直リンクのまま本番で使い続けると、リンク切れや表示速度の問題が出るため）。取得作業自体は
ビルド前の準備作業であって、実行時にAPIを呼び続けるものではないので、依頼のルールにある
「APIコストや呼び出し回数が増える変更」には当たらないと考えている。

写真の上に文字を乗せる箇所では、以前ふりかえり画面のヘッダーで文字が読みにくくなった不具合が
あったので、同じことが起きないよう可読性用のグラデーション/オーバーレイを必ず敷いてほしい。

## 進め方について

画面数が多い規模の大きい変更なので、無理に1回でやろうとしなくていい。

1. まず色・角丸・影・フォント・写真カードなどの共通の土台（デザイントークン／共通コンポーネント）を作る。
2. サイドバーの並び順（ホーム→予定・タスク→お金管理→メモ・リスト→Gmail→旅行計画→ふりかえり→設定→アカウント）
   で、画面ごとに順番に当てはめていく。
3. 見た目が一度に大きく変わる変更なので、本番へ入れる前にどこかの区切り（例えばHOME完了時点、
   全画面完了時点など）でこちらに確認を挟んでもらえるとありがたい。
4. 複数回のセッション・コミットに分けて進めて構わない。
