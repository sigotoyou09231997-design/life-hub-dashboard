# 予定・お金管理・メモが空のとき、背景の余白が広すぎる

## 何を変えたいか
予定の「今日」タブ、お金管理の「サマリー」タブ、メモ・リストの一覧など、
データが0件のとき、カード1〜2枚の下に何もない背景写真だけの帯が
画面の半分近く残ってしまう。

空の日や未設定の状態はこのアプリでは普通によく起きるので、その都度
画面が間延びして未完成っぽく見えてしまう。カード側を画面の高さに
合わせて伸ばす、または余白部分に案内文言やイラストを足すなどして、
間延びして見えないようにしてほしい。

## どの画面／どのデータか
- 予定・タスク管理画面の「今日」タブ（予定0件・タスク0件のとき）
- お金管理の「サマリー」タブ（給与未登録のとき）
- メモ・リストの一覧（メモ・チェックリスト・買い物リストが0件のとき）
他にも同じパターンで背景だけが余っている空状態があれば、気づいた範囲で
合わせて直してもらって構わない。

## 既存データをどう扱うか
見た目（レイアウト）だけの調整。既存データの扱いは変えない。
