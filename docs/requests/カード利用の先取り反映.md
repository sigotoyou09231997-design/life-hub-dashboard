# クレジットカードのまだ引き落とされていない利用分も残額に反映したい

## 何を変えたいか
「現在使える残額」は登録済みの支出(Transaction)ベースで計算しているが、
クレジットカードは利用してから引き落としまで日数が空くため、使ったのに
まだ反映されていない分がある。カードの利用明細（CSVやメール通知）を取り込んで、
未確定の利用分も残額の計算に含められるようにしたい。
PayPay明細の取込(paypayCsv.ts / PayPayImport.tsx)と同じような仕組みでよい。

## どの画面／どのデータか
お金管理TOP・支出関連。取込元はカード会社のCSVエクスポート、または
Gmailに届く利用通知メールのどちらか実現しやすい方でよい（判断はそちらに任せる）。

## 既存データをどう扱うか
既存の支出データには影響しない。新しく取り込んだ分だけ「未確定」として区別し、
実際の支出(Transaction)として確定した/されたときに二重計上しないようにする。
