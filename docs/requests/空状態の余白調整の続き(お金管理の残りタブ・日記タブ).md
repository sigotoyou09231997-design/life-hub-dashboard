# 空状態の余白調整、まだ残っている画面がある(お金管理の給与・固定費・履歴・PayPay、メモ・リストの日記)

## 何を変えたいか
以前「空状態の余白調整」でお金管理のサマリー・Gmail・メモ・リストの空状態は
直してもらったが、同じお金管理画面の中でも他のタブ、それとメモ・リストの
日記タブに、同じ症状がまだ残っている。

具体的には、データが0件のとき、カードの上のほうにメッセージとボタンだけが
小さく表示され、カードの残り(画面下の方まで)が何もない透明・すりガラスの
背景だけになっている。以前直してもらった画面と同じ直し方でよい。

## どの画面／どのデータか
- お金管理画面(/money 相当)の「給与」タブ：データ0件のとき
- お金管理画面の「固定費」タブ：データ0件のとき
- お金管理画面の「履歴」タブ：データ0件のとき
- お金管理画面の「PayPay」タブ：データ0件のとき
- メモ・リスト画面の「日記」タブ：日記が0件のとき

いずれもPC幅(1440px程度)で確認。デスクトップで確認したが、モバイル幅でも
同じ直し方で問題なければ合わせてほしい。

## 既存データをどう扱うか
見た目(レイアウト)だけの調整。既存データの扱いは変えない。
