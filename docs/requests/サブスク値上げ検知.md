# サブスクなど固定費の値上げに気づきたい

## 何を変えたいか
固定費(FixedCost)は金額を手で書き換えるだけで、変更したこと自体が記録に残らない。
毎月払いの固定費（サブスクなど）の金額を編集で変えたとき、「前回いくらだったか」が
あとで分かるようにしたい。値上げにあとから気づけるのが目的。

## どの画面／どのデータか
お金管理 → 固定費一覧・編集フォーム（FixedCostForm/FixedCostList）。
FixedCostの金額を編集して保存したタイミング。

## 既存データをどう扱うか
過去の変更履歴は残っていないので、これから変更した分だけ記録が増えていく形でよい。
遡って過去の金額を復元する必要はない。
