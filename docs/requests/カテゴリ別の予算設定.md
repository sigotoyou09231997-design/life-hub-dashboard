# お金管理で、カテゴリ別に予算を設定できるようにしたい

## 何を変えたいか
今の予算(オーバー通知)は月全体で1つの金額になっているようだが、
「食費」「交通費」のようにカテゴリごとに上限を設定できるようにしたい。
どのカテゴリで使いすぎているかが分かりやすくなるようにしてほしい。

既存の「予算オーバー通知」の仕組みと組み合わせて、カテゴリ別にも
通知できるとなお良い(必須ではない)。

## どの画面／どのデータか
お金管理のサマリー画面、および予算の設定部分(設定画面にあれば設定画面)。

## 既存データをどう扱うか
既存の全体予算の設定はそのまま残してよい。カテゴリ別の予算を追加で
持てるようにするだけでよい。
