# 画面が広いとき、空状態の中身が上に寄って余白が残る（メモ・リストで確認）

## 訂正
このファイルは元々「PC幅で開くと中身がスマホ幅のまま左上に張り付く」という
内容だったが、それは検証環境（Claude側の仮想ブラウザ）の表示の癖で誤検知
だったっぽい。カード自体の横幅は壊れていない（実測でも896px/1172pxまで
ちゃんと広がっていた）。この点はもう気にしなくて良い。

## 何を変えたいか（新しい内容）
本人が実際のブラウザ（Chrome、ウィンドウ幅は目視で1600px超）で
メモ・リスト画面（データ0件の空状態）を開いたところ、添付スクショの通り、
カード自体は横幅いっぱいに広がっているが、カードの中の上側に大きな空白が
残っていて、「メモ・リスト」の内訳（メモ/チェックリスト/買い物リスト）が
カードの下の方に寄ってしまっている。

Gmail・お金管理の空状態は既に直っている（カードが画面いっぱいまで伸びて
背景の帯が消えた）とのことなので、同じ空状態調整がメモ・リスト画面には
まだ効いていない可能性がある。同じ考え方でメモ・リストも直してほしい。

## どの画面／どのデータか
メモ・リスト画面（/records/notes）。メモ・チェックリスト・買い物リストが
すべて0件のとき。添付: screenshots/メモ画面_PC幅_空状態.png
（実際のChromeで撮影、ウィンドウ幅は目視で1600px超）

## 既存データをどう扱うか
見た目（レイアウト）だけの調整。データの扱いは変えない。
