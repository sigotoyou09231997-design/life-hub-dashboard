# PCのブラウザなど幅が広い画面で開くと中身が左上に寄ってしまう

## 何を変えたいか
スマホ幅（〜600px程度）では問題ないが、ブラウザの幅を広げて開くと
（タブレットやPCサイズ）、サイドバー（ホーム/予定・タスク/お金管理/
メモ・リスト/Gmail/旅行計画/設定/アカウント）自体はPC幅で表示される
ものの、メインの中身がスマホ幅のカードのまま画面の左上に張り付いて
しまい、残りの大部分が背景色だけの空間になってしまう。

タブレット幅（768px程度）ではサイドバーも出ないまま、同じように
中身が左上に寄った状態になる。

普段はスマホのPWAとして使うことが多いが、PCのブラウザで開いたときも
画面幅をちゃんと使うようにしてほしい。

## どの画面／どのデータか
全画面共通のレイアウトの土台の問題。確認したのは幅768px（タブレット）
と1440px（PC）。デスクトップ表示まわり（サイドバー＋メインコンテンツ
の幅の決め方）を見てほしい。

## 既存データをどう扱うか
レイアウトだけの変更。データの扱いは変えない。
