# 週次・月次でふりかえれる画面が欲しい

## 何を変えたいか
ホームは「今日」の状態しか出ていないので、1週間・1か月単位で
「使った金額」「完了したタスク数」「書いた日記の件数」くらいをまとめて
振り返れる画面(またはホームの新しいカード)が欲しい。
お金管理・予定タスク・メモの3つを横断して、生活全体がどうだったか
ざっくり見えるようにしたい。

具体的な項目・デザインの細かい部分はお任せします。

## どの画面／どのデータか
ホーム画面に新しいカードを追加する、または新しい画面(例: /review)を作る、
どちらでも構いません。使うデータは、既存のお金管理・予定タスク・メモの
記録から読み取る形。

## 既存データをどう扱うか
既存データは読み取るだけ。新しい保存先が必要な場合(表示設定など)は
新しく追加してよいが、既存の記録は変更・削除しない。
