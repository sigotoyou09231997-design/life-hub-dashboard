# 旅行のしおりを、他の人にも共有できるようにしたい

## 何を変えたいか
旅行計画の日程・持ち物・ルートなどをまとめて、一緒に行く人にも見せられる
共有リンク(閲覧のみでよい)が欲しい。既存のログイン中の自分のアカウント以外の
人が、リンクを開くだけで内容を見られるイメージ。

注記: これは今アカウント内(端末内)で完結しているデータを、他人にも見える形で
外に出す変更になるので、Supabase側の設定変更が必要になるかもしれません。
その場合は依頼のルールどおり、実装せず `.cowork/waiting.txt` に理由を書いて
止めてもらって構いません。

## どの画面／どのデータか
旅行計画の詳細画面(日程・費用・持ち物・ルート・日記の各タブ)。
共有リンクを開いた側には、編集はさせず閲覧だけで十分。

## 既存データをどう扱うか
既存の旅行データ自体は変更しない。共有用に見せる・見せないを選べるなら、
初期状態は「共有しない(非公開)」にしておいてほしい。
