# 判断待ちだった4件への回答

## 何を変えたいか

実行中の報告で「判断待ちで止まっている」と挙がった4件について、こちらの判断を返す。
それぞれ対応する既存の依頼メモに沿って進めてほしい。

### 1. 天気予報のAPI選定（`旅行日程の天気予報.md`）

Open-Meteoで進めてOK。APIキー不要・無料枠も十分なので、費用面の心配はいらない。

### 2. 位置情報リマインドの実現範囲（`位置情報トリガーのリマインド.md`）

アプリを開いている間だけ位置を見て判定する形（フォアグラウンドのみ）で進めてOK。
PWA・iOS Safariでバックグラウンドの位置監視は現実的でないので、その制約は受け入れる。

### 3. 為替換算（`海外旅行の為替換算.md`）

為替レートはAPIで自動取得しつつ、本人が手で上書きできるようにしてほしい
(カードの実際のレートと為替APIのレートが違うことがよくあるため)。
API候補はFrankfurter.app（ECB基準・無料・APIキー不要）を推奨。
金額は、外貨の元金額と円換算後の金額を端末内の別テーブルで持つ形にすること
（メモ欄への埋め込みは不可 — 別の実行で見つかった不具合と同じ扱いで直すこと）。

### 4. 年間集計エクスポート（`個人開発の収益経費の年間集計エクスポート.md`）

案件タグは自由入力のテキスト項目で十分（マスタ管理までは不要）。
エクスポートは「タグ別→その中で月別」の集計をCSVで出せればよい
（確定申告や自分の集計に使う想定）。
