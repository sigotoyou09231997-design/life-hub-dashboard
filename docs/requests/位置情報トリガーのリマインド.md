# 特定の場所に着いたら/離れたらリマインドしてほしい

## 何を変えたいか
今の通知(notifyMinutesBefore)は時間ベースだけなので、「駅に着いたら買い物リストを見る」
のように場所をトリガーにしたリマインドも欲しい。
PWA・iOS Safariでバックグラウンドの位置監視がどこまでできるかの制約が大きいはずなので、
技術的に厳しければ実現できる範囲（アプリを開いているときだけ判定する、等）を先に教えてほしい。

## どの画面／どのデータか
タスク(Task)・買い物リスト(Note/ShoppingItem)あたりに場所条件を持たせるイメージ。

## 既存データをどう扱うか
影響なし。場所条件は新規に設定したタスク・リストだけに付く。
