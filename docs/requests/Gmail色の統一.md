# Gmailだけアイコンの色がナビと画面内でズレている

## 何を変えたいか
予定=青、お金管理=オレンジ、メモ=紫、というふうに機能ごとに色分けが
されていて分かりやすいが、Gmailだけ下部ナビのアイコンは赤系なのに、
Gmail画面内のアイコンや「Gmailを接続」ボタンは青になっている。

他の画面はナビの色とページ内の色がちゃんと揃っているので、Gmailも
下部ナビと同じ赤系の色に揃えてほしい。

## どの画面／どのデータか
Gmail画面（/gmail）内の、青色になっているアイコン・接続ボタンなど。
下部ナビのGmailアイコンの色（赤系）に合わせる。

## 既存データをどう扱うか
見た目の色だけの変更。データには影響しない。
