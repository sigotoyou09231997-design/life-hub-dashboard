# 新デザイン(design/warm-photo-refresh)のスマホ幅で、下のナビが壊れている

## 何を変えたいか

`design/warm-photo-refresh` ブランチを本人が手元で `npm run dev` して確認したところ、
PC幅（デスクトップ）は全画面おおむね問題なさそうだったが、**スマホ幅で下部ナビが壊れている**。

添付のスクリーンショット3枚（実際にブラウザで撮ったもの）を参照：

- `screenshots/バグ_モバイル下ナビ_ホーム画面_余白.png` — ホーム画面。下部ナビ(予定/お金管理/メモ/Gmail)が
  画面下に固定されておらず、コンテンツの直後にそのまま流れて表示されている。そのせいで画面の残り(元は
  スクロール分のはずの領域)が真っ白(クリーム色)の余白のまま何もなく続いている。
- `screenshots/バグ_モバイル下ナビ_お金管理画面_文字重なり.png` — お金管理画面。もっと悪化していて、
  下部ナビが「貯金目標」カードの上に重なって表示されており、「目標の合計 ¥35,000/月」などの文字が
  ナビのアイコンやテキストと重なって読めなくなっている。
- `screenshots/バグ_モバイル下ナビ_予定タスク画面.png` — 予定・タスク画面。同じく下部ナビが
  「期限切れのタスク」カードに重なっていて、「請求書をまとめて送る」の文字がアイコンで隠れている。

見た感じ、下部ナビが `position: fixed` で画面下に固定されず、通常のコンテンツの一部として
ドキュメントの流れに混ざってしまっている（もしくは固定はされているが、コンテンツ側に
ナビの高さぶんの `padding-bottom` が入っていない）ように見える。今回の土台の作り直し
（`src/styles/theme-warm.css` など）でモバイルナビ周りを触った際に崩れたのではないかと思う。

## どの画面／どのデータか

スマホ幅（375px程度）で全画面共通のレイアウト部分。具体的には下部ナビのコンポーネント
（モバイル用のタブバー）と、各ページのメインコンテンツ領域の余白/固定位置の関係。
見た限りホーム・お金管理・予定タスクで再現しているので、特定の画面ではなく共通レイアウトの問題だと思う。

## 既存データをどう扱うか

見た目・レイアウトのみの不具合。データは関係ない。

## 進め方について

これは新デザインの土台部分のバグなので、残り画面（お金管理/メモ・リスト/Gmail/旅行計画/
ふりかえり/設定/アカウントのカード組み替え）を進める前に、まずこれを直してほしい。
直ったら `design/warm-photo-refresh` ブランチのままでいいので、スマホ幅でホーム・お金管理・
予定タスクの3画面を実際に確認してから次に進んでほしい。

なお、本題ではないので直さなくていいが参考までに: 旅行計画・旅行詳細のヒーロー写真カードだけ、
今までの「暗い写真に白文字」のトーンが残っていて、他の画面の明るいクリーム基調と少し浮いて見える。
気になるようなら次の段階で見てほしい（今回のバグ修正の対象ではない）。
