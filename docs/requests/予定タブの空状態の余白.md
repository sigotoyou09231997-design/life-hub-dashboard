# 予定・タスク管理の「今日」タブも、空状態の余白が広すぎる

## 何を変えたいか
Gmail・お金管理・メモ・リストの空状態は既に直してもらったが、
予定・タスク管理画面の「今日」タブにも同じ問題が残っている。

添付スクショの通り、予定が0件・タスクが0件のとき、左側の
タイムライン（6/12/18/24の時間軸、予定なし）と右側のタスクカードの
両方に、実際の内容の下に何もない広い空白が残ってしまっている。
他の画面と同じ考え方で、カードが間延びして見えないように調整して
ほしい（カードの高さを内容に合わせる、余白に案内を足す、など
やり方は任せる）。

## どの画面／どのデータか
予定・タスク管理画面（/schedule）の「今日」タブ。予定0件・タスク0件の
とき。左のタイムラインカードと、右の「今日のタスク」カードの両方。
添付: screenshots/予定タブ_今日_空状態.png
（実際のChromeで撮影、ウィンドウ幅は目視で1100px超）

## 既存データをどう扱うか
見た目（レイアウト）だけの調整。既存データの扱いは変えない。
