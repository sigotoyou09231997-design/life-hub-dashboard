# 判断待ちへの回答（旅行のしおり共有／為替換算SQL／個人開発年間集計SQL）

## 何を変えたいか

保留中だった3件について判断したので、実装を進めてください。

### 旅行のしおりを共有

- 公開範囲: ログイン不要のリンク限定公開（URLを知っている人だけ見られる）。検索エンジンにインデックスされないようnoindexを付けてください。
- 含める内容: デフォルトで含めるのは日程・持ち物・ルートのみ。日記と費用はデフォルトで除外。費用だけは共有設定画面でトグルON/OFFできるようにしてください（同行者と割り勘の確認に使いたい場合があるため）。日記は個人的な内容なので今回は共有対象に含めない設計にしてください（トグルも不要、常に非公開）。
- リンクの無効化: 共有をOFFにしたら既存のリンクは即座に無効（アクセスすると「共有は終了しました」等の表示）にしてください。再度ONにする場合は新しいURLを発行する形で構いません（トークンの使い回しはしない）。

レートの取得方法は今まで通り「まずAPI(Frankfurter.app)から自動取得、失敗したら手入力」のハイブリッドのままで進めてください。ただし直前の本番確認でAPIが503を返して失敗するケースを確認したので、取得失敗時はその費用の編集画面を次に開いた時に自動で再取得を試みるようにしてほしいです（すでに手入力済みの値は上書きしない。未入力の場合のみ再取得を試みる）。
