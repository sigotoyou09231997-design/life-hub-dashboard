# 自動実行（cowork-daemon）が動いているのが見えるようにしたい

## 何を変えたいか
今の`scripts/cowork-daemon.sh`は、`docs/requests/`への書き込みを検知すると
`claude -p "/cowork-check"`を完全にバックグラウンド・無人（ヘッドレス、
出力はheadless-out.txt/err.txtにリダイレクト）で実行していて、画面には
何も表示されない。

本人が使っている別プロジェクト（ホームページ制作の「sophia」フォルダ）は
Coworkと連携すると、実際にClaude Codeが動いている様子が見える仕組みに
なっているらしい。todoアプリの方もそれに合わせて、依頼を検知して実装が
走っているとき、本人が「今動いている」と分かるようにしてほしい
（例えば見えるターミナル／ウィンドウで実行する、進捗をどこかに
リアルタイムで出す、など。やり方はこちらで判断して構わない。
「sophia」フォルダがどう連携しているか分からなければ、本人に聞いてよい）。

## どの画面／どのデータか
アプリの画面ではなく、`scripts/cowork-daemon.sh`まわりの実行の仕方の話。
`.cowork/`配下のログ・状態ファイルの運用は変えなくてよい。

## 既存データをどう扱うか
アプリのデータには影響しない。自動化の仕組み自体の変更。
