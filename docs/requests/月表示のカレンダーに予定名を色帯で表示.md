# 月表示のカレンダーに、点だけでなく予定名も色付きの帯で表示したい

## 何を変えたいか

いまカレンダー(MonthView.tsx)の月表示は、日付の下に「誰の予定か」で色分けした
点(collectPersonDotsInRange, 1日最大3つ)が並ぶだけで、その日に何の予定があるかは
日付を選んでから下の一覧(EventList.tsx)を見ないと分からない。

TimeTreeのように、日付のマス自体に予定名を色付きの帯（チップ）で直接表示して、
月を開いた時点で「いつ・誰の・何の予定か」が一目で分かるようにしたい。
参考画像: `docs/requests/screenshots/参考_TimeTree_月表示に予定名表示.png`
（家族・全社スケジュール・実家などカレンダーごとに色を分け、マスの中に
「大掃除」「帰省」「パパ預かり」のように予定名がそのまま文字で入っている）。

このアプリの「誰の予定か」(EventPerson / personIds)は、TimeTreeでいう
カレンダーごとの色分けと同じ役目をすでに持っている
(src/lib/eventPeople.ts, PersonTags.tsx, PersonFilter.tsx)。今回はその色を、
点ではなく予定名入りの帯として月表示のマスに出す変更、という位置づけ。

## どの画面／どのデータか

予定・タスク管理 → カレンダータブ(SchedulePage.tsx → MonthView.tsx)。
色の出し方は既存のcollectPersonDotsInRange(src/lib/eventPeople.ts)を土台にしてよいが、
色だけでなく予定のtitleも一緒に日付ごとに集める必要がある。

対応が必要になりそうな点（判断はそちらに任せる）:
- 件数の上限は設けない。その日に入っている予定は「+2件」のようにまとめず全部帯で出す
  （本人の指示: 「入ってる予定分出して欲しい。多分タイムツリーもそうしてる」。
  参考画像の1/22のマスも、4件分の帯でマスの高さが伸びている）。
- 件数が多い日はマスの高さがその分伸びる前提でよい。1行に収まらない予定名は
  省略記号などで省略してよい
- 対象は「誰の」が付く予定(CalendarEvent)を優先。タスク(taskDates)・旅行の予定
  (tripDates)を同じ帯形式にするか、今まで通り点のままにするかは見やすさ優先で判断してよい
- 予定を複数人に付けている場合の帯の色（今の点と同じ扱いでよい）

## 既存データをどう扱うか

データ構造・保存内容は変えない。表示だけの変更。
「誰の」フィルタ(PersonFilter)で絞り込んだときは、帯もその絞り込みに従う
（今の点の絞り込みと同じ挙動）。
