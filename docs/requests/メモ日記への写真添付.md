# メモ・日記に写真を添付できるようにしたい

## 何を変えたいか
今のメモ・日記は文字だけのようなので、レシートや現地の写真を添付できる
ようにしたい。旅行の日記や、買い物メモ・仕事の記録としてもっと使いやすく
なると思う。

注記: 写真の保存先によってはSupabase側のストレージ設定が必要になるかも
しれません。その場合は依頼のルールどおり実装せず、`.cowork/waiting.txt`
に理由を書いて止めてもらって構いません。端末内(IndexedDB)だけで収まる
形であれば、そのまま進めてもらって構いません。

## どの画面／どのデータか
メモ・リスト画面のメモ編集、および旅行の日記・旅行外の日記の編集画面。

## 既存データをどう扱うか
既存のメモ・日記のテキストには影響しない。写真は任意の追加項目として
持たせるだけでよい。
