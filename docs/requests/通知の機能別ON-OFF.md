# 通知を機能ごとにON/OFFしたい

## 何を変えたいか
設定画面には「バックグラウンド通知」という全体スイッチが1つあるだけで、
タスクの通知・旅行予定の通知・固定費の通知などを個別に切ることができない。
機能ごとに通知のON/OFFを分けられるようにしたい。

## どの画面／どのデータか
- 設定画面の通知欄
- 対象：タスクの通知、予定の通知、固定費・支払日の通知、旅行予定の通知など、
  すでにnotifyMinutesBefore/notifyDaysBeforeを持っている機能

## 既存データをどう扱うか
既存の全体スイッチはそのまま残し、その配下に機能別のトグルを追加する形でよい。
個別設定が無い状態（初期値）は、全体スイッチに従う（今まで通り）扱いにする。
