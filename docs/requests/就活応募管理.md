# 就活の応募先を管理できる機能が欲しい

## 何を変えたいか
予定・タスク管理に、就活の応募先ごとの進捗(書類選考・一次面接・二次面接・内定など)
を一覧で見られる、簡単な管理機能を追加したい。会社名・現在の段階・次の予定日くらいが
分かれば十分。予定・タスク管理画面にある実際の面接の予定と、ゆるく紐づけられると
なお良い(必須ではない)。

具体的な項目・見せ方はお任せします。

## どの画面／どのデータか
予定・タスク管理画面に新しいタブ、または独立した新しい画面、どちらでも構いません。

## 既存データをどう扱うか
既存の予定・タスクのデータには影響しない。新しいデータの置き場所を追加するだけ。
