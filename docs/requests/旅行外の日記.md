# 日記を旅行中以外でも書けるようにしたい

## 何を変えたいか
DiaryEntry型はtripIdが任意になっていて、旅行に紐付かない日記も書ける前提の作りに
見えるが、実際に呼び出しているのはTripDetailPage（旅行の詳細画面）だけで、
旅行中以外に日記を書く導線が無い。旅行の有無に関わらず日常的に日記を書けるようにしたい。

## どの画面／どのデータか
- 新しい日記の入り口（メモ・リストの中に置く、あるいは独立した導線でも、実装しやすい方でよい）
- DiaryEntry（既存の型・保存ロジックはそのまま使う。tripIdは無し(undefined)で保存する）

## 既存データをどう扱うか
既存の旅行内の日記機能・データはそのまま残す。今回は「旅行に紐付かない日記」を
新しく書けるようにする追加のみ。
