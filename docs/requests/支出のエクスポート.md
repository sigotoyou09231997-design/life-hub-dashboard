# 支出データを書き出せるようにしたい

## 何を変えたいか
CSV取り込み（銀行明細・PayPay・給与明細）は充実しているが、書き出し側が
backup.tsの全データJSONダンプしかない。家計簿として見返したり、確定申告のときに
使えるような、支出（Transaction）の一覧をCSVで書き出せるようにしたい。

## どの画面／どのデータか
- お金管理の支出履歴の画面（既存のエクスポート導線があれば近くに、無ければ設定画面のデータ管理欄でもよい）
- 対象データ：Transaction（収入・支出）。期間を指定して絞り込めるとなお良いが、必須ではない

## 既存データをどう扱うか
既存のバックアップ機能(JSON)はそのまま残す。今回追加するのはCSV形式での書き出しのみ。
