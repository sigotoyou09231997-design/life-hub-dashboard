# 新デザイン（design/warm-photo-refresh）を本番へ

## 何を変えたいか

`デザインを暖色・写真ベースの新デザインに全面刷新.md`と`新デザイン_第2段_残り8画面を進める.md`、
どちらも本人が確認して「これで良い、本番に出してほしい」とのことなので、
`design/warm-photo-refresh`ブランチの内容を`main`へ入れて、本番（Vercel）に反映してほしい。

## どの画面／どのデータか

全画面のUI（見た目）。データ・挙動は変わらない。

## 既存データをどう扱うか

触らない。

## 進め方について

念のため、mainへ入れる前に最新のmainを取り込んで（rebase/mergeどちらでも構わない）、
型チェック・テストが通ることを確認してからpushしてほしい。終わったら`.cowork/report.md`等の
いつもの記録も残しておいてほしい。
